# Штучний інтелект у державних закупівлях: аналіз Prozorro

Збір і аналіз закупівель, у яких публічні замовники прямо згадують штучний інтелект, нейромережі, машинне навчання,
генеративні й мовні моделі, ChatGPT/OpenAI чи Copilot. Період — з 1 січня 2025 року.

Результат — звіт `docs/index.html` (GitHub Pages) і CSV-таблиці в `data/`:
- динаміка оголошених закупівель за місяцями, окремо — генеративний ШІ;
- що купують: обладнання, програмне забезпечення, ІТ-послуги, навчання, консалтинг;
- рейтинги постачальників і замовників за сумою договорів (назва + ЄДРПОУ);
- список усіх закупівель зі згадкою ШІ, включно зі скасованими й тими, що тривають.

## Запуск

1. **Actions → «Оновлення даних про закупівлі штучного інтелекту» → Run workflow**:
   спершу `probe` (перевірка текстового пошуку), потім `all`.
2. Далі дані оновлюються автоматично щовівторка.
3. Звіт — GitHub Pages з папки `/docs` гілки `main`.

Локально: `python3 ai.py probe`, `python3 ai.py all` (Python 3.10+, без залежностей).

## Файли

| Файл | Що містить |
|---|---|
| `config.json` | період, пошукові запити, шаблони згадок ШІ, категорії за CPV, групи замовників |
| `overrides/tenders.csv` | ручне виключення хибних збігів (`tender_id,action,note`, де action = `exclude`) |
| `overrides/buyers.csv` | ручне віднесення замовника до групи за ЄДРПОУ |
| `data/tenders.csv` | усі закупівлі зі згадкою ШІ: де саме згадано, які терміни, категорія, статус |
| `data/contracts.csv` | договори за цими закупівлями |
| `data/suppliers.csv`, `data/buyers_rank.csv` | рейтинги постачальників і замовників |

## Методологія

**Відбір.** Окремого CPV для ШІ немає, тож кандидатів знайдено текстовим пошуком prozorro.gov.ua (запити — у `config.json`).
У вибірку йде закупівля, лише якщо згадку ШІ знайдено в назві, описі, лоті чи позиції за шаблонами `ai_patterns`.
Згадки на кшталт «клавіша Copilot» виключено. Пошук не індексує прямі договори (звіти) і переговорні процедури,
тож вони до вибірки не потрапляють.

**Обсяг згадки.** «Весь тендер» — ШІ в назві чи описі або в усіх позиціях; «окремі позиції» — лише в частині.
У другому випадку сума договору може містити й інші товари.

**Сума.** Поточна вартість договору з допугодами; для виконаних і розірваних — фактично сплачена, якщо вказано.
Це зобов'язання, а не платежі.

Дані: Prozorro, відкриті дані з правом повторного використання за умови посилання на джерело.
